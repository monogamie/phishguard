Серьёзность: **высокая** — врёт пользователю или падает; **средняя** —
портит объяснение или ухудшает балл; **низкая** — косметика.

## Находка 1. Короткое название одной строкой

- **Зона:** ложные тревоги / пропуски / кривой ввод / интерфейс / ревью кода
- **Серьёзность:** высокая
- **Проверил сам запуском:** да / нет — и почему нет
- **Что не так:** одно предложение, без предисловий.
- **Как воспроизвести:**

```bash
cd backend && python3 -c "
...точная команда, которая показывает проблему...
"
```

- **Ожидали:** …
- **Получили:** …
- **Где в коде:** `файл.py:123` (если нашлось; если нет — так и написать)
- **Заметка:** всё, что не влезло выше. Необязательно.
